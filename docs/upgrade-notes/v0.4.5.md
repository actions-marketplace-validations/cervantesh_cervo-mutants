# Upgrade Notes for v0.4.5

## Summary

- `v0.4.5` ships mutator signal quality fixes, baseline/CI gate wiring into
  `cervomut run`, and hardened public report contracts for Phase 2.
- Import-path strings are no longer mutated (they only ever compile-error).
- Provably equivalent struct tags (primarily matching yaml defaults) are marked
  `equivalent_risk: high`; non-empty `json` names are never marked that way.
- Gate policy failures exit `1` for every named gate, with a structured `gate`
  block on the mutation report.
- CI/Action smoke validates mutation-report **content**, not only file presence.

## Operator Action

- If you pin the GitHub Action by tag, move from `@v0.4.4` to `@v0.4.5` after
  this release is published.
- If you install via `go install`, upgrade with:
  `go install github.com/cervantesh/cervo-mutants/cmd/cervomut@v0.4.5`.
- Expect slightly fewer compile-error-only string mutants and clearer
  equivalent-risk labels on struct-tag survivors; mutation totals may drop
  where import paths were previously counted.
- If you use baseline/CI gate flags on `run`, treat process exit `1` as a policy
  verdict for any failed gate check, not only `fail_under`.

## Rollback

- If this release causes unexpected behavior, pin the GitHub Action back to
  `cervantesh/cervo-mutants@v0.4.4`.
- Reinstall the prior CLI:
  `go install github.com/cervantesh/cervo-mutants/cmd/cervomut@v0.4.4`.
- If you install from release archives, reinstall the previous `v0.4.4` archive
  for your target platform.
